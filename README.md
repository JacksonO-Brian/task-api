# 🧠 Task Management API

A scalable RESTful API built with Node.js and Express for managing tasks with authentication and role-based access control.

---

## 🚀 Features
- User authentication (JWT)
- Role-based authorization
- Create, Read, Update, Delete (CRUD) tasks
- Secure API endpoints
- Error handling & validation

---

## 🛠️ Tech Stack
- Node.js
- Express.js
- MongoDB
- JWT (Authentication)

---

## 📦 Installation

```bash
git clone https://github.com/jacksono-brian/task-api.git
cd task-api
npm install
▶️ Run the App
npm start
📌 API Endpoints
Method	Endpoint	Description
POST	/register	Register user
POST	/login	Login user
GET	/tasks	Get all tasks
POST	/tasks	Create new task
PUT	/tasks/:id	Update task
DELETE	/tasks/:id	Delete task
